# Marketing Experimentation & Growth Strategy

**应该触达谁、选择哪种营销邮件，以及如何分配有限预算？**

本项目用真实随机实验完成商业决策分析，重点是证据、统计判断和管理建议。数据来自 Kevin Hillstrom 2008 年公开的 MineThatData 挑战：64,000 名客户、男装邮件／女装邮件／不发邮件三组随机分配，观察两周内的访问、购买和消费。它是历史研究，不是已落地的营销增长案例。

## 商业问题 → 实验 → 发现 → 策略 → 建议

| 真实计算结果 | 商业意义 |
|---|---|
| 男装邮件购买率增量 **0.681 个百分点**，95% CI **0.500–0.861** | 相对不发邮件，确实增加购买；男装邮件可作简单基准。 |
| 女装邮件购买率增量 **0.311 个百分点**，CI **0.150–0.472** | 也增加购买，但平均效果较弱。三项购买率比较均通过 Holm 校正。 |
| 男装／女装每名分配客户增量消费 **$0.770／$0.424** | 增量不同于总销售；缺少成本与利润率，不能声称真实利润或 ROI。 |
| 50% 容量下，细分策略比随机男装投放多 **$0.055/客户**，配对 CI **−$0.261–$0.372** | 尚无可靠证据证明定向策略优于简单随机分配。 |
| 对照组购买预测 AUROC **0.654**，Brier 仅略优于常数预测 | 更容易自然购买，不等于更容易被营销促成购买。 |

**建议：以男装邮件作新实验基准，保留不发邮件的随机对照；预算受限时，以相同预算检验细分策略相对随机男装投放的增量优势。不能按最高点估计直接宣布赢家。**

## 留出样本策略比较

32,000 名独立留出客户。下表假设利润贡献率 **40%**、每封邮件成本 **$0.02**，按每 10,000 名候选客户缩放。金额是**假设条件下的增量贡献估计**，不是已实现利润。

| 策略 | 发信数 | 增量贡献估计 | 点态 95% CI |
|---|---:|---:|---:|
| 不发邮件 | 0 | $0 | $0–$0 |
| 全量男装邮件 | 10,000 | $3,073 | $1,468–$4,677 |
| 全量女装邮件 | 10,000 | $1,486 | $71–$2,901 |
| 随机男装邮件，50% | 5,000 | $1,638 | $555–$2,720 |
| 按自然购买概率发男装邮件，50% | 5,000 | $1,468 | $226–$2,709 |
| 按细分增量选择邮件，50% | 5,000 | $1,859 | $692–$3,025 |

全量投放消耗两倍预算；判断定向价值需比较相同容量策略的配对差异。每封 $0.02 时，$50／$100／$200 分别支持最多 25%／50%／100% 容量；成本提高到 $0.10 时，同样容量需 $250／$500／$1,000。[108 个情景](reports/tables/scenario_grid.csv)同时改变成本、利润贡献率、容量和最低贡献门槛，允许少发或不发。

## 方法和能力

- **数据审计：** 固定原始文件校验值，核对字段、缺失、域值及结果一致性。6,562 条字段相同记录缺少客户 ID，不能擅自去重；只修正 `Surburban` 拼写。
- **SQL 与 Python：** SQLite 查询客户画像、各组分配客户分母、细分汇总，并与 pandas 独立对账。
- **实验推断：** 购买率比例检验、Welch 消费检验、效应量、95% 区间、每个结果的三项 Holm 比较和 Bonferroni 敏感性区间；最大标准化不平衡 0.0169。
- **客户细分：** 实验前购买时间与品类历史；六个实际出现群体。探索性细分使用预定 16 项检验族校正，不能用实验后的购买结果选客户。
- **解释性模型：** 对照组 logistic 自然购买基线，固定权重的细分消费部分汇总；预测只使用实验前属性。
- **独立策略评估：** 固定种子 20080320、按处理组划分 50%／50%，使用原实验 1/3 分配概率的 Horvitz–Thompson 增量估计和配对策略区间；不反复用测试集调参。
- **商业决策：** 六张从真实汇总生成的图、双语管理层备忘录和预算敏感性分析，清楚区分消费、增量和假设利润贡献。

## 可复现与证据边界

环境、完整运行命令与目录说明见 [English README](README.md#reproduce-locally)。支持 Python 3.12／3.13；依赖固定，测试包含手算、随机化无偏性、划分独立性和容量边界。Notebook 已执行，只展示汇总信息。CI 核验代码、单元测试和固定汇总图表，不自动下载原数据；完整原始数据复现单独记录在 [验证报告](reports/validation.md)。小型合成数据只用于单元测试，所有项目分析均来自原始实验。

发布者邀请公开分析，但未查到明确原始客户数据再分发许可。仓库不包含原始数据或逐客户预测，只提供来源、下载步骤、校验值和汇总结果。MIT 仅覆盖原创代码和文档。

## 限制与下一步

2008 年数据不能证明当前营销效果；两周、578 名买家导致消费区间较宽；没有实际利润率、成本、退订、投递和长期价值。男装与女装消费差异的 Holm p=0.0305，但更保守 Bonferroni 区间跨零。探索性异质性和策略点态区间不能证明个人 uplift，也不能证明哪个人“不用营销也会买”。分析方案是回溯性固定方案，不是前瞻预注册。

下一轮以**相同预算**随机比较男装基准、细分增量策略和不发邮件，提前固定规则，采集真实利润贡献与退订数据，并由管理层定义值得投入的最小效应。[完整备忘录](reports/executive_memo.zh-CN.md)。

项目补足现有供应链、B2B 销售、RAG 和客户调查中的**营销实验＋统计推断＋客户策略＋资源分配**能力。[项目差异审查](docs/project-positioning.md)。
